# Personal Portfolio & Interactive Quiz

## Purpose
A personal portfolio webpage built to showcase my profile, skills, and an interactive multiple-choice quiz with theme switching.

## Features
- Responsive personal profile with About and Skills sections
- Dark / Light Mode theme toggle using JavaScript
- Interactive 5-question multiple-choice quiz with live score tracking and restart option

## Technologies Used
- HTML5, CSS3, Vanilla JavaScript
- Cursor AI Code Editor
- GitHub & Vercel (Hosting and Deployment)
